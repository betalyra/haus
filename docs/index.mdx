Most data formats leave the meaning to conventions: a `type` field, dates as strings, floats for money, `null` for three different things. **haus writes the meaning into the data**, and every language reads it exactly the same way.

```haus
// Order 1042: shipped, paid in euros, a gift.
{
  id: 1042,
  total: Money(30.30, EUR),
  status: Shipped { at: Instant("2026-11-08T09:12:00Z") },
  items: [
    { sku: "TEA-01", quantity: 2 },
    { sku: "MUG-07", quantity: 1, gift: True },
  ],
}
```

Hover a value to see its type. No schema needed.
