# haus for Roc

Built against the Roc nightly compiler (2026-11-03) and basic-cli 0.26.0.

| Path | Contents |
|---|---|
| [`package/`](package) | The haus package: `Value` (data model and parser), `Decode`, `Encode` (compact writer), `Stream` (reads a stream chunk by chunk), `Time` (the std/time profile) |
| [`examples/`](examples) | The same examples as in TypeScript and Rust, on the same files in [`../examples`](../examples), plus `shop`, a Roc showcase |

## Examples

| Example | Shows |
|---|---|
| [`quickstart`](examples/quickstart) | `thread.haus`: typed data, decoding, encoding, errors |
| [`order`](examples/order) | `order.haus`: schema packages (`@haus/money`, `@haus/geo`) and codecs |
| [`logs`](examples/logs) | `logs.haus`: a stream, read chunk by chunk and written back |
| [`shop`](examples/shop) | Roc's structural types: handlers for any union or record with certain tags or fields (row polymorphism) |

Run each from its folder, because the examples read the shared files by relative path:

```sh
cd examples/quickstart && roc main.roc
cd examples/order && roc main.roc
cd examples/logs && roc main.roc
```

## Generated modules

Each example's types and decoders come from its schema, like in TypeScript
(content mapper) and Rust (`haus-build`). Roc has no build scripts, so the
modules are generated by `haus-gen` and checked in, like protobuf output:

| Schema | Module |
|---|---|
| `thread.schema.haus` | [`quickstart/Thread.roc`](examples/quickstart/Thread.roc) |
| `logs.schema.haus` | [`logs/Logs.roc`](examples/logs/Logs.roc) |
| `order.schema.haus` | [`order/Order.roc`](examples/order/Order.roc), and [`order/Typed.roc`](examples/order/Typed.roc) with codecs |
| `@haus/money`, `@haus/geo` | [`HausMoney.roc`](../extensions/money/roc/HausMoney.roc), [`HausGeo.roc`](../extensions/geo/roc/HausGeo.roc): Roc packages next to the npm and Cargo ones |

After changing a schema, regenerate them (`haus-gen` is part of
[`haus-build`](../rust/haus-build), so this needs Rust):

```sh
examples/gen.sh
```

| haus | Roc |
|---|---|
| `{ a: T, b?: U }` | `{ a : T, b : [Missing, Present(U)] }` |
| `< A \| B T \| C { … } >` | `[A, B(T), C({ … }), Unknown(Str, List(Value))]`, without `Unknown` when closed |
| `Maybe a`, `Result e a` | `[None, Some(a)]`, `Try(a, e)` |
| `Array a`, `Map v` | `List(a)`, `List((Str, v))` |
| `Int`, `Int8`…`UInt64`, `Float64` | `I128`, `I8`…`U64`, `F64` |
| `Decimal`, `Date`, `Instant`, … | `Str`: exact text, std/time checked by its profile |

A codec is a Roc module with a `Target` type, `decode : Base -> Try(Target, Str)`
and `encode : Target -> Base` ([`Cents.roc`](examples/order/Cents.roc)), chosen
with `--codec ID=MODULE` when generating.

## Tests

```sh
cd package && roc test ConformanceTest.roc && roc test TimeTest.roc
cd package && roc test Decode.roc && roc test Encode.roc && roc test Stream.roc
cd examples/shop && roc test main.roc
```

`ConformanceTest.roc` is generated from `../test-suite` by
`scripts/gen_conformance.py`, and `TimeTest.roc` holds the same std/time
cases as the TypeScript and Rust bindings.
